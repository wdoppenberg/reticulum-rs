## How to Use This Testing Harness

### Generate New Test Vectors (Python)

```bash
cd tests/compat
source .venv/bin/activate
pytest test_formats.py test_crypto.py -v -s
```

This creates/updates JSON files in `vectors/`.

### Run Rust Validation Tests

```bash
cargo test -p reticulum-core --test python_compat -- --nocapture
```

This reads the vectors and validates Rust matches.

### Add New Compatibility Tests

1. **Python**: Add test in `test_formats.py` or `test_crypto.py`
   - Generate test vector JSON
   - Ensure it captures expected behavior

2. **Rust**: Add test in `python_compat.rs`
   - Load test vector
   - Perform operation
   - Assert equality
